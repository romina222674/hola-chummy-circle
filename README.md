# Ñande Reko Radio - Sitio Web

Sitio web oficial de **Ñande Reko Radio**, una emisora online de Corrientes, Argentina, dedicada a la difusión del chamané y la música tradicional litoraleña.

## 🎙️ Características

- **Streaming en vivo 24/7** - Transmisiones de chamané y música tradicional
- **Información de contacto** - Números de teléfono y correo
- **Servicios publicitarios** - Spots, flyers creativos y gestión de redes sociales
- **Interfaz moderna y responsiva** - Diseño elegante adaptado a todos los dispositivos
- **Imágenes de fondo naturales** - Fotografías de fauna y flora local del litoral

## 🚀 Cómo Usar

1. Clona este repositorio
2. Abre `index.html` en tu navegador
3. Personaliza los links de WhatsApp y Zeno.fm en `script.js`
4. Sube las imágenes a la carpeta `images/`
5. Despliega en tu hosting preferido

## 🔗 Enlaces Importantes

- **WhatsApp**: Reemplaza `TU_NUMERO_AQUI` con tu número de WhatsApp
- **Zeno.fm**: Link de streaming en vivo
- **Redes Sociales**: Conecta tus perfiles en el footer
